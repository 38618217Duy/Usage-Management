# Prompt Examples

Real-world examples demonstrating prompt engineering principles in action.

---

## Example 1: Product Website Development

**Type:** Task Prompt with Technical Requirements

```markdown
### Task
Please develop a professional AI Agent product website, including complete page content and interactive features.

### Product Content Requirements
Please include the following core modules in the website:
- Product Introduction: Clearly introduce the product's core value and positioning
- Product Features: Detailed display of main features and capabilities
- Core Advantages: Highlight the product's competitive advantages and differentiated characteristics
- Usage Scenarios: Specific application scenarios and user cases

### Design Style Guide
**Overall Style**: Minimalist modern, strong tech feel

**AI Element Representation**:
- Use gradient colors, geometric shapes, and other tech elements
- Incorporate AI-related icons and visual symbols
- Adopt modern typography and layout design

### Technical Implementation Requirements
- Use HTML5, CSS3, JavaScript to build responsive pages
- Ensure good compatibility in mainstream browsers
- Optimize page loading speed and user experience

### Delivery Standards
- Function Verification: Conduct page access testing after development to ensure all functions work properly
- Online Deployment: Provide a directly accessible online page link
- Code Delivery: Provide complete HTML, CSS, JS source code files

### Output Requirements
- Complete website source code (HTML/CSS/JS)
- Online access link after deployment
- Function testing verification report
- **Important**: Need to provide the above content links or files in the final task summary
```

### Analysis

| Principle | Implementation |
|-----------|----------------|
| Structured | Clear sections: Task → Content → Design → Technical → Delivery → Output |
| Specific Goals | Exact deliverables listed (source code, link, report) |
| Measurable Output | Explicit file types and verification requirements |
| Emphasis | **Important** marker for critical requirements |

## Example 2: Product Research Report

**Type:** Role-Based Prompt with Quality Standards

```markdown
### Role Definition
You are a professional product manager with a deep technical background and keen market insights, skilled in writing high-quality product research reports.

### Task
Generate a comprehensive AI Agent product research analysis report

### Specific Requirements

#### Report Structure (Must include the following 9 sections)
1. Product Overview - Product definition, classification, and current development status
2. Product Positioning - Main application scenarios and value proposition
3. Target Users - User profiles, demand analysis, and market segmentation
4. Business Model - Profit model, pricing strategy, and revenue structure
5. Market Analysis - Market size, growth trends, and driving factors
6. Competitor Analysis - Comparison of mainstream products (at least 5-8 typical products)
7. Core Features - Key technical capabilities and feature characteristics
8. Technical Architecture - Underlying technology stack and architecture design
9. Summary and Outlook - Industry trend predictions and development recommendations

#### Content Quality Standards
- Data Support: Provide specific market data, user scale, financing information, etc.
- Information Timeliness: Focus on the latest development trends
- Analysis Depth: Not only describe the current situation but also analyze reasons and trends

### Output Format
Deploy the report content as a static webpage, including:
- Clear hierarchical headings
- Data comparison tables
- Key point lists
- Key information highlighting
- Total word count controlled between 8000-12000 words to ensure moderate information density, both comprehensive and focused.
- **Important**: Need to provide the deployed static webpage link in the final task summary

### Important Reminder
⚠️ Please pay special attention:
- Ensure the accuracy of all data and information
- Maintain an objective and neutral analytical perspective
- Avoid overly marketing-oriented expressions
```

### Analysis

| Principle | Implementation |
|-----------|----------------|
| Role Definition | Clear persona with specific expertise |
| Structured | Hierarchical: Role → Task → Structure → Quality → Output → Reminder |
| Specific Goals | 9 required sections with descriptions |
| Quality Standards | Data requirements, timeliness, analysis depth |
| Measurable | Word count range (8000-12000), competitor count (5-8) |
| Emphasis | ⚠️ icon, **Important** markers for critical points |

---

## Key Patterns Demonstrated

### 1. Section Organization
Both examples use consistent section headers:
- `### Task` - What to do
- `### Requirements` - Specific needs
- `### Output` - Expected deliverables

### 2. Layered Specificity
- High-level goal first
- Then detailed requirements
- Then quality standards
- Finally output specifications

### 3. Emphasis Techniques
- **Bold** for key terms
- ⚠️ Icons for warnings
- Bullet points for scannable lists
- Numbered lists for sequences

### 4. Measurable Criteria
- Specific counts: "5-8 products", "9 sections"
- Word ranges: "8000-12000 words"
- File types: "HTML, CSS, JS"
- Verification steps: "testing report"
